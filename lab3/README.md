# Лабораторная работа №3

**Выполнил:** студент 3 курса группы МОА-241 Коник Илья

## Цель работы

Освоить разработку приложений на PyQt с интерфейсом, созданным в QtDesigner. Работа с файлами, изображениями, QPainter, диалоговыми окнами и слайдерами.

## Задания

**№1. Анализ чисел из файла (1 балл)**  
Кнопка «Загрузить» открывает диалог выбора `.txt` с целыми числами (разделёнными пробельными символами). Выводятся максимальное, минимальное и среднее значения. Кнопка «Сохранить» записывает результаты в файл. Предусмотрена обработка ошибок формата.

**№2. Текстовый редактор (1 балл)**  
Простой редактор: открыть файл, создать новый, сохранить изменения. Отображение через `QTextEdit`.

**№3. Редактор изображений (1 балл)**  
При старте открывается диалог выбора квадратного изображения. Возможности: оставить один из цветовых каналов (R/G/B), повернуть на 90° влево/вправо. Все изменения — в реальном времени.

**№4. Регулятор прозрачности (1 балл)**  
Диалог открытия изображения + `QSlider` для регулировки alpha-канала. Обработка пикселей через NumPy.

**№5. Генератор флага (1 балл)**  
Создаёт изображение полосатого флага. Количество цветов вводится через диалог выбора числа из диапазона. Цвета генерируются случайно.

**№6. Смайлик (2 балла)**  
Средствами `QPainter` рисуется смайлик. Цвет выбирается через диалог, масштаб — слайдером.

**№7. Фортепиано (2 балла)**  
Кнопки, каждая из которых проигрывает определённую ноту. Звуки через `QSoundEffect`.

**№8. L-системы (3 балла)**  
Построение L-систем по определению из текстового файла (название, число углов, аксиома, теоремы). Первый шаг строится автоматически, переключение шагов — слайдером.

## Файлы

- `main.py` — точка входа
- `*.ui` — формы из QtDesigner
- `ui_*.py` — сгенерированные из `.ui` файлы
