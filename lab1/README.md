# Лабораторная работа №1

**Выполнил:** студент 3 курса группы МОА-241 **Коник Илья**

## Цель работы
Освоить разработку приложений с графическим пользовательским интерфейсом на **PyQt**: работа с базовыми виджетами (`QLineEdit`, `QPushButton`, `QCheckBox`, `QPlainTextEdit`), обработка сигналов и слотов, компоновка элементов на форме.

## Задания

### №1. Перекидыватель слов (1 балл)
На форме расположены два поля ввода и кнопка со стрелкой, направленной от первого поля ко второму. При нажатии кнопки строка из первого поля перебрасывается во второе, а стрелка на кнопке меняет направление. При повторном нажатии строка летит обратно, стрелка возвращается в исходное положение.

### №2. Вычислитель выражений на PyQt (1 балл)
В однострочное поле вводится корректное арифметическое выражение. По кнопке «Вычислить» результат вычисляется через `eval()` и выводится в другое поле.

**Пример:** `1 + 2 * 3` → `7`

### №3. Универсальные чекбоксы (2 балла)
На форме размещены три и более произвольных виджета, рядом с каждым — `QCheckBox`. Один универсальный обработчик скрывает и показывает виджеты в зависимости от состояния соответствующего чекбокса (без отдельного обработчика на каждый чекбокс).

### №4. Азбука Морзе (2 балла)
На форме — кнопки с латинскими буквами и поле ввода. При нажатии на кнопку в поле добавляется код этой буквы из азбуки Морзе. Кнопки создаются в цикле, а не вручную.

### №5. Заказ в ресторане (3 балла)
Пользователь выбирает одно или несколько блюд. У каждого блюда есть цена и количество порций (по умолчанию — 1, если блюдо выбрано). В чеке (виджет `QPlainTextEdit`) отображается: название блюда, количество, итоговая стоимость по каждому блюду и общая сумма заказа.

### №6. Калькулятор (3 балла)
Калькулятор работает с вещественными числами (положительными и отрицательными) и выполняет сложение, вычитание, умножение и деление. Действия выполняются последовательно. При делении на ноль выводится сообщение об ошибке.
