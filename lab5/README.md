# Лабораторная работа 5 — «Средства для работы с ОС»

В проекте находятся 10 отдельных решений. Запускать команды нужно из корневой папки `lab5_os`.

## Установка зависимости

```bash
python -m pip install -r requirements.txt
```

Библиотека `schedule` требуется только для задания 5. Остальные задания используют стандартную библиотеку Python.

## Запуск заданий

```bash
python 1/main.py
python 2/main.py archive.zip
python 3/main.py .
python 4/main.py source_folder destination_folder
python 5/main.py
python 6/main.py --sort name=Vasya age=42
python 7/main.py 5 string 1
python 8/main.py 3 5
python 9/main.py --sort name=Vasya age=42
python 10/main.py --frame-height 10 --frame-width 30 filename.txt
```

Для Windows можно использовать обратные слеши в путях, например `python 2\\main.py archive.zip`.

## Примечания

- Задание 1 анализирует файлы в текущей рабочей папке, из которой запущена команда; каталоги не выводятся.
- Задание 2 строит дерево ZIP-архива с отступом в два пробела на каждый уровень вложенности.
- Задание 3 ранжирует 10 самых крупных элементов непосредственно внутри указанного каталога. Для папок учитывается суммарный размер всех вложенных файлов; файлы также выводятся, как в примере из задания.
- Задание 4 создаёт ZIP-архив исходной папки. В имени архива указаны дата и время с точностью до секунды.
- Задание 5 запускает вывод каждый час в `00` минут. Количество повторов «Ку» соответствует 12-часовому формату текущего часа.
- Задание 6 использует `sys.argv`, задание 9 реализует ту же логику через `argparse`.
- Задание 10 использует приложенный `filename.txt`. Файл оставлен в корне проекта, поэтому последняя команда запускается без изменения пути.
