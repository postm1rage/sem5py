## Цель работы
Освоить проектирование интерфейсов в **QtDesigner** и разработку приложений на **PyQt** с использованием компоновок (`Layout`), виджетов выбора (`QRadioButton`, `QCalendarWidget`, `QTimeEdit`, `QListWidget`, `QDoubleSpinBox`) и строки состояния (`QStatusBar`).

## Задания

### №1. Текстовый флаг (1 балл)
Приложение «Текстовый флаг». Пользователь выбирает цвет для каждой из трёх полос флага с помощью `QRadioButton` (3–5 вариантов на полосу). По кнопке «Нарисовать» выводится сообщение с выбранными цветами, например: «Красный, Зелёный, Белый». Размер окна запрещено изменять.

### №2. Ежедневник (3 балла)
Программа-ежедневник с использованием `QCalendarWidget`, `QTimeEdit` и `QListWidget`. Пользователь вводит название события, выбирает дату и время, нажимает «Добавить» — событие появляется в списке. События отсортированы по возрастанию даты.

### №3. Записная книжка (3 балла)
Приложение «Записная книжка». Пользователь вводит имя контакта и номер телефона. После добавления данные отображаются в `QListWidget`.

### №4. Игра «Псевдоним» (4 балла)
Графический интерфейс для игры «Псевдоним»: в куче N камней, игроки по очереди берут не более 3 камней, побеждает взявший последний. Количество камней задаётся перед началом новой игры. Оставшееся количество камней отображается на экране. Пользователь играет против компьютера и первым делает ход, выбирая, сколько камней взять (предусмотрены ошибочные значения). ИИ должен выигрывать всегда, когда это возможно (стратегия: дополнять ход соперника до 4).

### №5. Антиплагиат (4 балла)
Приложение на PyQt с использованием `Layout` для простейшей проверки на антиплагиат. На форме:
- виджет задания порога срабатывания (например, `QDoubleSpinBox`);
- кнопка расчёта результата;
- виджет отображения результата сравнения (вывод в `QStatusBar` с выделением нужным цветом).

Сравнение текстов выполняется построчно (возможен и собственный алгоритм).
